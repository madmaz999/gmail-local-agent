# Gmail Local Agent

A personal, single-user tool that runs on my own computer and reads my own
Gmail mailbox through the Gmail API. It uses the read-only scope
(`https://www.googleapis.com/auth/gmail.readonly`) to search messages and
download attachments for my own use.

- **Who uses it:** only the developer, with their own Google account.
- **Where it runs:** locally on the developer's machine. There is no server,
  website, or hosted service.
- **What it does:** lists, reads, and searches email, and saves attachments
  to the local disk.

See [PRIVACY.md](PRIVACY.md) for how data is handled.
