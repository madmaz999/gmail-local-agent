# Privacy Policy

Last updated: October 2026

Gmail Local Agent is a personal tool used only by its developer to access
the developer's own Gmail account.

## Data accessed
With the user's consent, the app requests read-only access to Gmail
(`gmail.readonly`). This lets it read messages, metadata, and attachments.

## How data is used
Email data is processed locally on the developer's own computer and is
used only to provide the app's functionality for the developer.

## Storage and sharing
- Data is not sent to any server operated by the developer.
- Data is not sold, shared, or transferred to any third party.
- Data is not used for advertising.
- Data is not used to train generalized AI or machine learning models.
- OAuth tokens are stored locally in a file on the developer's computer.

## Retention and deletion
Local copies can be deleted at any time by deleting the files on the
developer's computer. Access can be revoked at any time at
https://myaccount.google.com/permissions.
